# Конструктор зачёта v4

Загрузите на GitHub Pages все файлы с сохранением структуры.

При добавлении темы:
1. Добавить новый `topics/<тема>.js`.
2. Добавить тему в нужный раздел `topics.js`.
3. `index.html` менять не нужно.

v4 загружает файлы тем после загрузки реестра и не использует `document.write`.
