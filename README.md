# Конструктор зачёта — модульная версия

На GitHub загрузите всё содержимое папки с сохранением структуры.

- `index.html` — интерфейс и логика. При добавлении темы не меняется.
- `topics.js` — реестр разделов и тем.
- `topics/*.js` — банки карточек.

## Как добавить тему
Например, «Металлы»:
1. Создать `topics/metals.js` по образцу существующих файлов.
2. В `topics.js` в разделе «Неорганическая химия» добавить:
   `{title:"Металлы", file:"topics/metals.js"}`
3. На GitHub заменить `topics.js` и добавить `topics/metals.js`.

Сам `index.html` переписывать не нужно.
